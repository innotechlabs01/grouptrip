# MVP & Product Management

## MVP — Phase 1: Core

- Trip: create, invite, participants
- Decisions: polls, votes, results → configuration
- Budget: categories, items, expenses
- Fund: goal, contributions, progress
- Payments: individual payment, authorized contributions, history
- Dashboard: everything summarized

## MVP Core Loop (User Journey)
```
REGISTER
   ↓
CREATE TRIP
   ↓
INVITE FRIENDS
   ↓
CREATE POLLS
   ↓
SELECT DESTINATION
   ↓
CREATE BUDGET
   ↓
CREATE FUND
   ↓
FRIENDS JOIN
   ↓
AUTHORIZE CONTRIBUTIONS
   ↓
FUND GROWS
   ↓
PAY RESERVATIONS
   ↓
TRIP
   ↓
EXPENSES
   ↓
SETTLEMENT
   ↓
COMPLETED
```

## North Star Metric
**Funded Trips** — trips with:
- participants
- budget
- financial goal
- at least one contribution received

## KPIs (to refine)
- Trips created
- Trips funded (North Star)
- Fonded rate (funded / created)
- Time from create to first contribution
- Contribution success rate
- Payment failure rate
- Fund completion % (collected / goal)
- Invite → join conversion

## Product Flywheel
CREATE TRIP → INVITE FRIENDS → MORE USERS → CREATE FUND → PAYMENTS → BOOK SERVICES
→ PROVIDER REVENUE → BETTER EXPERIENCE → MORE TRIPS
